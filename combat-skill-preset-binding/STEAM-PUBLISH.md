# Steam 创意工坊发布

## 首次发布

1. 启动《太吾绘卷》，进入“模组选择 → 上传”。
2. 待上传模组文件夹选择本项目的 `publish/CombatSkillPresetBinding`。
3. 可见性选择“公开”。
4. 更新简述填写：`首次发布：让每套运功预设独立保存并自动切换功法突破预设。`
5. 确认上传，并在 Steam 页面接受创意工坊协议。
6. 上传成功后，不要手工修改游戏写回 `Config.lua` 的 `FileId`。

## 发布后验证

1. 订阅创意工坊版本。
2. 暂时停用本地开发版本，避免加载两个同名插件。
3. 重启游戏，确认 Mod 显示作者 `SMD`、版本 `0.2.2.0`。
4. 在运功预设二为同一功法选择突破预设贰，在运功预设三选择壹。
5. 往返切换两套运功预设，确认功法突破预设分别恢复。
6. 保存、退出并重新载入存档，再验证一次绑定持久化。

## 后续更新

使用游戏“上传模组”管理中的已有项目更新，保留原 `FileId`，提高 `Version` 并填写本次更新简述。

当前创意工坊项目编号：`3762445301`。

更新时使用 `publish/CombatSkillPresetBinding-0.2.2`，不要使用首次上传后留下的旧目录；旧目录曾被游戏写入本地临时编号 `FileId = 3`。

0.2.2 更新简述：`修复创意工坊包错误携带本地调试设置的问题，详细日志现在默认关闭；适配游戏 1.0.56。`

不要上传 `Settings.Lua` 或 `.pdb` 文件。测试 Steam 订阅版本前，应确保游戏安装目录的 `Mod` 文件夹中没有同一 `FileId` 的本地开发副本，否则游戏设置界面会同时识别 `Source = 0` 和 `Source = 1`，导致保存设置时报错。
