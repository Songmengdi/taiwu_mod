# 护肝交互

《太吾绘卷》前后端 MOD，用来集中大地图人物交互、略过不承载选择的奇遇说明与结果确认，并减少重复鼠标操作。

依赖独立 MOD **Taiwu UI Framework**。如果统一人物交互页因兼容性问题不可用，原版人物交互入口仍然保留。

## 统一人物交互页

仅在世界大地图按 `~` 打开全屏人物交互页；再次按 `~`、`Esc`、鼠标右键或窗口关闭按钮可逐层关闭。MOD 不替换原版人物点击入口，也不接管奇遇、战斗等其他类型的交互。

左侧使用原版大地图风格的人物卡片，可切换“当前地格 / 同道 / 商人·商队”：同道严格取人物界面左侧队伍并排除太吾本人；当前地格会排除已单列的商人；商人分类沿用原版地格人物页判定并保留卡片左侧状态标志，商队也可从同一页进入。右侧按“常用 / 其他 / 不可用”显示人物当前的原生交互。选择原生交互后仍进入游戏原有流程，完成并返回大地图时会重新读取人物状态并恢复本页，因而可以直接切换到下一个人。打开交互中心时会在后台预载商店界面，减少第一次浏览货物的等待。

右上角设置可增删及调整常用交互顺序，修改立即写入游戏的全局持久化目录，所有存档共用。默认顺序为：显示人物、浏览货物、交换私人藏书、赠送礼物、知心而交、慧眼识珠、交换物品。当前不满足条件的常用项自动归入“不可用”。第三方 MOD 注册到原生人物交互表中的选项也会动态显示；没有专用图标时使用通用图标。

## 集市首次到达说明

MOD 适配当前游戏中的 14 个集市入口：文山书海阁、公输坊、回春堂、奇货斋、五湖商会、服牛帮和大武魁各自的小型集会与大型春日集市区域。

这些入口仍由 GameData 后端正常触发，因此 `AdventureRuntime` 的 `onlyOnce` 记录、事件进入脚本和任务状态都会照常执行。在 `SetDisplayingEventData` 发布边界，MOD 根据游戏实际生成的选项判断后续动作：

- 恰好一个可见选项：在后端选择它，不向前端发布该层说明；
- 大型春日集市的首次教程菜单：按七个教程事件及各自“赶紧去买东西”选项的精确白名单，在后端直接略过；
- 其他两个及以上选项：停止快进并正常发布，让玩家自行选择；
- 事件结束：正常发出清空通知并结束事件链。

大型集市教程由游戏事件队列在入口调用结束后延迟发布，因此教程白名单不依赖入口调用栈；普通单选说明仍只会在已确认的 `onlyOnce` 集市入口作用域内略过。

快进仅由已确认的 14 个 `onlyOnce` 集市入口启动，不会作用于其他奇遇，也不会全局自动点击所有单选事件。

## 打坐休息

休息点第一层保留“打坐休息 / 暂且作罢”的真实选择。玩家选择打坐后，恢复效果由游戏原生逻辑正常结算。结果事件随后由监听器加入事件队列，并不是“打坐休息”选项的直接后继事件。

MOD 让后端的 `UpdateEventDisplayData` 完整执行结果事件的原生脚本，确保精力恢复和休息点状态正常结算；随后在 `SetDisplayingEventData` 发布边界识别该结果事件，在显示数据发送给前端之前选择其唯一选项“如此便好”，并取消发布。因此前端不会创建第二个窗口、遮罩或转场。

## 奇遇数字键交互

奇遇元素如果同时配置了“抵达自动触发”和“手动交互”，MOD 会屏蔽前者，避免太吾走到商人、设施等地格时被强制拉入事件；该元素仍会保留在当前地格的交互列表中，可由玩家主动点击或按 `1` 触发。只有抵达事件、没有手动入口的剧情与机关不受影响。

奇遇地图左侧交互列表存在项目时，按主键盘或小键盘的 `1` 会触发第 1 项：休息点会打开原生“打坐休息 / 暂且作罢”选择，出口会打开原生退出确认。确认窗口取得焦点后，MOD 不再接管按键，再按一次 `1` 由游戏原生快捷键选择第 1 个选项。

该功能直接调用列表项目绑定的游戏交互入口，不模拟鼠标坐标；只有项目位于太吾当前地块、奇遇地图处于顶层且搜索框未在编辑时才生效。

在世界大地图上，太吾当前地格存在奇遇图标时，按 `1` 会调用该图标原生的进入奇遇入口，无需先用鼠标点击图标。该快捷键只查找 `MapElementAdventureRemake`，不会触发同一地格上的人物交互。

## 构建与本地部署

```powershell
dotnet build .\LiverFriendlyInteractions.Backend.csproj -c Release
dotnet build .\LiverFriendlyInteractions.Frontend.csproj -c Release
```

Release 构建会部署到游戏目录下的 `Mod\护肝交互\`。
