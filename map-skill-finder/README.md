# 太吾寻访

“太吾寻访”是使用 Taiwu UI Framework 2.0 构建的原生风格全屏寻访工具。

- 功法书：按门派、类别与具体功法选择目标后，自动优先查询太吾当前地域；当地无人持有时才扫描全图，并将命中地域按持有人数量排列为紧凑 Sheet。按真实存在的书页状态（总纲、正逆练、完整／残缺／亡佚）点选目标。
- 技艺书：按技艺类别、品级与具体书籍选择目标；同样基于实际持有书页状态点选目标。
- 拼书组合：混合私人藏书和背包副本，在读取的持有人上前端本地求解，按人数由少到多列出组合，调整书页目标即时重算。
- 地图标记：查询地域为太吾当前所在地域时，每套组合可将持有人所在地格标记为临时地格标记（标记后自动关闭窗口）。
- 人物：按姓名、身份品级、年龄、性别、门派及最多三条技艺资质／造诣条件查找。
- 商会：按商人／商队／商会、七家商会、一级至七级及商队状态查找具体实体。
- 地域：一次只查询一个未被侵袭地域，包含未显示地块；支持门派地域、大城市、其他地域两级筛选。
- 查询不会计算路径、距离、行动力或旅行成本，也不提供导航。

详细产品边界见 `docs/PRD-taiwu-xunfang.md`。
