# 太吾寻访 1.0.5.0 更新说明

可直接粘贴到 Steam 创意工坊的“更新简述”：

> 寻访范围现在会优先查询太吾所在地域，并可一键扩展到全地图；结果按地域分组展示，功法书、技艺书、人物、商会与任侠均支持此流程。同月重复打开会复用结果，减少反复读取。同步优化了结果区布局、地域页签和地图标记操作的层级与样式。

完整说明：

- 功法书、技艺书、人物、商会、任侠均改为本地域优先搜索；需要时可点击“搜索全图”。
- 全域结果按命中数量排列为紧凑的地域页签，单一或少量地域不会被横向拉伸。
- 同一游戏月内重新打开保留已搜索的功法书结果；手动重新读取或跨月后才重新查询。
- 重构结果工具栏：地域切换、重新读取与全图搜索归入同一操作区；“标记地格”等行内操作改为低干扰的描边按钮。
- 修复未选中页签悬停时出现白色背景的问题。

上传目录：`publish/地图功法找人`。

上传前确认其中只包含 `Config.lua`、`Cover.jpg` 与 `Plugins/` 下的两个 DLL 及其 deps 文件；不要上传 PDB 或本地设置文件。
