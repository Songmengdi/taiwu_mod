# 太吾寻访 1.0.6.0 更新说明

可直接粘贴到 Steam 创意工坊的“更新简述”：

> 寻访结果现已使用游戏原生人物卡，并优化重复查询与大量结果的浏览体验；标记目标会在重开界面后自动置顶回显，交流或移动后也会及时刷新人物持有物与可交互状态。

完整说明：

- 人物结果与功法书、技艺书持有人改用游戏原生人物卡，显示头像、姓名、门派职位、品级徽章和好感标志。
- 门派职位沿用游戏原生品级配色，例如掌门、长老和弟子的称号按品级显示不同颜色。
- 悬停人物卡可查看游戏原生人物详情，并支持 Alt、Shift 查看扩展信息。
- 与太吾位于同一地格的人物卡可直接点击并进入原生人物交互；异地人物仍可悬停查看，但不可点击，并通过卡片背景区分。
- 寻访窗口关闭后保留界面与人物卡实例，再次打开不再整体销毁重建。
- 地域目录在同一游戏会话内复用，仅以轻量世界状态检查更新当前位置和跨月变化，不再每次打开重复读取。
- 功法书、技艺书和人物查询结果增加缓存；人物展示数据按需批量获取，只加载当前实际显示的人物。
- 原生人物卡改为固定占位并逐帧挂载，降低首次显示大量结果时的单帧峰值和布局抖动。
- 人物展示缓存设有容量限制，并在游戏月份变化后自动失效，兼顾性能与信息时效性。
- 标记地格后重新打开寻访中心，已标记条目会在对应页签置顶并显示“已标记”，地域页签自动切换到目标所在地域。
- 与人物交流后会在下次打开窗口时重新查询，避免好感度与持有物信息仍显示旧状态。
- 太吾在同一地域内移动时也会即时刷新人物卡的“可交互/仅查看”状态。
- 修复反复开关窗口时，已销毁文本对象仍被延迟刷新而产生的异常。
- 修复“查看更多”人物组合时，原生人物卡异步刷新可能触发的空引用问题。

兼容性：适配游戏版本 1.0.58.0；需要前置 Taiwu UI Framework 2.1.6.0。
