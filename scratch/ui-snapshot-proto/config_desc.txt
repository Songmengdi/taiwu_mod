	Description = [[太吾绘卷调试探针·双端增强版 —— 在游戏内启动 MCP 服务，供 AI 代理实时查询和操控游戏状态。

【功能】
游戏加载后监听 localhost:13131，以模型上下文协议（MCP）向 AI 代理（Kimi Code、Claude Code 等）暴露 22 个工具：UI 快照/点击/输入/悬停/滚动/等待、截图、前端反射求值、热加载、大地图移动，以及 GameData 后端权威状态只读查询。

【UI 工具用法（snapshot → ref → action）】
1. taiwu_ui_snapshot 拍摄当前界面：场景摘要 + 顶层窗口语义树（@eN 引用、角色、状态）。
2. 用 @eN 调用 taiwu_ui_click / fill / toggle / hover / scroll，动作后自动返回变化 diff。
3. taiwu_ui_describe 查看组件全限定类名与所在程序集，配合反编译或 taiwu_eval 追踪代码。

【MCP 客户端配置示例】
{ "mcpServers": { "taiwu": { "url": "http://localhost:13131/mcp" } } }

【兼容性】
适配游戏 1.0.56.0。本 Mod 是 https://github.com/magian1127/TaiwuProbe 的双端扩展分支，增加了 GameData 后端探针与 Agent 向 UI 工具。请勿与创意工坊原版「调试探针」同时启用（端口 13131 冲突）。

【安全提示】
默认开启的 taiwu_backend_csharp 允许在 GameData 主线程执行任意 C#，仅供本机调试；不需要时请在 Mod 设置中关闭「启用任意 C# 后端执行」。
