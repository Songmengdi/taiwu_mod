# Taiwu UI Framework 2.1.6.0 更新说明

可直接粘贴到 Steam 创意工坊的“更新简述”：

> 优化原生组件与长列表体验：支持保留隐藏窗口、分帧挂载重型组件、追加列表内容并在界面重建后恢复滚动位置，减少依赖 MOD 反复打开界面和浏览大量结果时的卡顿与跳动。

完整说明：

- 新增 KeepAlive 窗口生命周期，窗口关闭时可保留已构建视图，再次打开无需整体销毁重建。
- 原生组件宿主新增明确的释放回调，便于依赖 MOD 安全实现对象池与缓存。
- 原生组件宿主支持延迟挂载，可将较重的游戏原生组件分散到后续帧处理。
- 延迟挂载期间立即建立固定尺寸布局，避免内容逐步出现时产生界面跳动。
- 新增追加列表能力，依赖 MOD 可增量显示更多结果，无需重建整个列表。
- 动态宿主重建后可恢复纵向滚动位置，减少刷新内容时的视图跳动。
- 文本节点支持显式宽度，便于构建尺寸稳定的复杂列表布局。
- 修正窗口隐藏、重新显示和父节点停用过程中的原生组件生命周期处理。
- 保持程序集兼容版本不变，已有依赖旧版框架的 MOD 可继续加载。

上传目录：`publish/TaiwuUiFramework`
