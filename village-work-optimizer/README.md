# 太吾村本月最优排班

V1.1 按照用户调整的优先级生成一套本月建筑人员安排：

- 最高资产收益
- 最高人才培养
- 最高威望收益
- 最高招人收益
- 最高资源收获，包括食材、木材、金铁、玉石、药材、毒物与织物

进入太吾村建筑总览后，点击底部工具栏的“村务排班”打开预览；`F8` 是备用入口，只在建筑总览已经打开时生效。可以调整五种目标的先后顺序再计算。V1.1 不会修改存档或自动设置岗位。

## 当前计算范围

- 从后端读取真实太吾村建筑、成人村民、儿童和当前岗位；
- 同一个人物不会被分配到多个建筑；
- 经营与资源方案使用主事与成人伙计的原生造诣贡献结构，并优先跨越本月进度阈值；
- 培养方案要求主事身份匹配，并优先安排资质差大、潜力充足的学生；
- 不安排同道。

V1.1 的综合方案仍使用分层启发式：高优先级目标先跨越有效结算线，跨线后将剩余人员交给下一目标。后续版本会按建筑事件类型逐步替换为完整银钱、资源、威望、招募和教学公式，并加入可调保护率。
